# Figures

## Manuscript figures

| File | Manuscript | Generated by |
|---|---|---|
| `Figure1_CARE_Agent_architecture.png` | Figure 1 | `scripts/make_figure1.py` |
| `Figure2_integrated_risk_tier.png` | Figure 2 | `scripts/make_figure2.py` |

These are the exact images embedded in the submitted manuscript. Both are produced
by the scripts in `scripts/`, so they can be regenerated rather than edited by hand.

Regenerating a PNG will not reproduce the published file byte-for-byte — matplotlib
embeds metadata and font metrics vary between systems — but the content is identical.

### Data dependency

`make_figure1.py` is a schematic and needs no data.

`make_figure2.py` reads the 395-patient clinical dataset, which is **not** part of this
public release (see the Data Availability statement in the manuscript). It falls back to
the bundled 4-record demo file in `data/`, which will not reproduce the published figure.
To regenerate it from the restricted dataset:

    CARE_AGENT_DATA=/path/to/dataset.xlsx python3 scripts/make_figure2.py
